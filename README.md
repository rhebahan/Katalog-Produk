# Katalog-Produk
Aplikasi desktop sederhana untuk mengelola katalog produk, dibuat dengan JavaFX dan SQLite. Produk ditampilkan dalam bentuk kartu, lengkap dengan fitur tambah, edit, dan hapus data (CRUD).

## Fitur
- Tambah produk: isi nama, harga, dan pilih foto, lalu simpan.
- Edit produk: klik tombol Edit pada kartu, form terisi otomatis, lalu Simpan Perubahan atau Batal.
- Hapus produk: klik tombol Hapus pada kartu, dengan dialog konfirmasi sebelum data dihapus.
- Tampilan katalog berbentuk kartu (foto, nama, harga, ID) dan jumlah produk ditampilkan otomatis.
- Validasi input: nama wajib diisi, harga harus angka bulat lebih dari nol, dan foto wajib dipilih.
- Penyimpanan lokal: data tersimpan di file SQLite dan dibuat otomatis saat aplikasi pertama kali dijalankan.
